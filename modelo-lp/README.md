# Modelo de landing page

Para criar uma nova LP, execute na raiz do repositório:

```bash
node scripts/create-lp.mjs <slug> "Título da página"
```

A nova pasta conterá `index.html` e `config.js`. Na maior parte dos casos, edite apenas o `config.js`.

Antes de publicar, revise:

- público e problema principal;
- título, promessa e CTA;
- parâmetro `origem`;
- textos de limite e privacidade;
- visual em desktop e celular;
- fluxo até o Tally e `/obrigado/`.

A documentação completa está em `../LANDING_PAGES.md`.
